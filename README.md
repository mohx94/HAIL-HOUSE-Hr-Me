# لوحة متابعة الموظفين (GitHub Pages + Excel)

صفحة ويب تعرض داشبورد حي يقرأ بياناته مباشرة من ملف `employees.xlsx` — بدون أي سيرفر أو قاعدة بيانات. كل ما تحتاجه هو تعديل ملف الإكسل ورفعه (Commit) على GitHub، وتنعكس التغييرات في الصفحة فورًا عند فتحها.

## هيكل الصفحة (قائمة جانبية)

الصفحة الآن تطبيق متعدد الصفحات بقائمة جانبية بدل التمرير الطويل:

| الصفحة | المحتوى |
|---|---|
| 🏠 الرئيسية | مركز العمليات: عدد الإجراءات العاجلة اليوم، زر "ابدأ العمل" (يفتح معالجًا يعرض كل إجراء لحاله مع خياري "تم" / "تخطي")، إحصائية سريعة عن العقود، وآخر 10 تنبيهات |
| 👥 الموظفون | كل الموظفين بجدول واحد، والضغط على أي اسم يفتح بطاقة تفصيلية (العقد + الهوية + كل سجلات الإجازة) |
| 📄 العقود | إحصائية أعلى الصفحة (إجمالي / تنتهي خلال شهر / منتهية) + فلترة بالقسم والحالة + بحث + ترتيب + زر "تعليم كمُعالَج" وزر "✉️ خطاب تجديد" لكل صف |
| 🪪 الهويات | نفس الفكرة (بما فيها زر "✉️ خطاب تجديد")، مع دمج عمود "القسم" تلقائيًا من شيت العقود (حتى لو ما كان موجودًا أصلاً بشيت الهويات) |
| 🏖 الإجازات | تقويم شهري ← الإجازات الحالية ← الإجازات القادمة ← تعارضات الإجازات ← ترتيب الأقسام حسب عدد الإجازات |
| 🔔 التنبيهات | كل التنبيهات مجمعة حسب اليوم (اليوم / غدًا / بعد كذا يوم) مع إمكانية تعليم "تم" |
| 📊 التقارير | 4 رسوم بيانية (حالة العقود، حالة الهويات، أكثر الأقسام إجازات، الاستحقاقات القادمة) + توقع الضغط لـ6 أشهر |
| ⚙️ الإعدادات | تحديث البيانات، معاينة ملف محلي، حد التنبيه، وملاحظة بالحقول غير المتوفرة حاليًا |

## خطاب التجديد بالبريد الإلكتروني (✉️)

بصفحتي العقود والهويات، كل صف فيه زر **"✉️ خطاب تجديد"** — يفتح مسودة بريد جاهزة ببرنامجك الافتراضي (Outlook أو غيره) فيها:
- اسم الموظف وتاريخ الانتهاء الحقيقي (من الملف)
- عدد الأيام المتبقية الفعلي (يُحسب تلقائيًا من تاريخ اليوم، وليس رقمًا ثابتًا)
- نص الخطاب جاهز، وتقدر تراجعه وتعدّله قبل الإرسال

**قبل أول استخدام:** روح لصفحة ⚙️ الإعدادات واكتب اسم المستلم (اللي يظهر في "السيد ... المحترم") وبريده الإلكتروني (اختياري) — تُحفظ هذي البيانات بمتصفحك وتُستخدم تلقائيًا في كل خطاب.

> ملاحظة: الزر يفتح مسودة فقط، ولا يرسل شيء تلقائيًا — الإرسال الفعلي يصير من برنامج البريد نفسه بعد ما تراجع المحتوى.

## قيود مهمة يجب معرفتها

- **لا يوجد كتابة رجوعًا لملف Excel.** أزرار "تم" / "تعليم كمُعالَج" بصفحة العقود والهويات ومعالج "ابدأ العمل" تُخفي التنبيه من متصفحك فقط (تُحفظ محليًا) — **لا تُعدّل تاريخ العقد أو الإقامة في الملف نفسه.** تحديث البيانات الحقيقي لازم يصير بتعديل ملف الإكسل نفسه ورفعه.
- **لا توجد صفحة مستقلة (URL) لكل موظف.** بدلها بطاقة تفصيلية (Modal) تفتح عند الضغط على اسم الموظف — لأن إنشاء صفحة فعلية لكل موظف من الـ180 يحتاج بنية توليد ملفات مختلفة تمامًا.
- **"سجل الإجراءات" لكل موظف غير متوفر.** لأن الموقع ثابت (Static) بدون قاعدة بيانات، فما فيه طريقة لحفظ تاريخ من عمل أي إجراء ومتى — يحتاج نظام حقيقي بخادم.
- **الحقول التالية غير موجودة بالملف الحالي وتحتاج إضافتها كأعمدة جديدة إذا احتجتها:** الفرع، المدير المباشر، تاريخ المباشرة، الجنسية، تاريخ الميلاد، المخالفات.
- **صور الموظفين، الرواتب، الآيبان، والمرفقات (شهادات/عقود/خطابات) لم تُبنَ بعد.** هذي تحتاج تخزين ملفات حساسة، وبما أن المستودع الحالي **عام (Public)**، وضع هذي البيانات فيه غير آمن. لو تبي هذي الميزات مستقبلًا، الأفضل الانتقال لحل بمستودع خاص أو نظام حقيقي بخادم.

## أفكار مؤجَّلة تحتاج نقاش قبل البناء

الأفكار التالية تحتاج بيانات إضافية حساسة (راتب، آيبان، صور، شهادات) أو بنية تحتية مختلفة (تخزين ملفات، توليد خطابات رسمية):
- صفحة موظف كاملة بصورة وراتب ومرفقات
- توليد خطابات رسمية (تجديد/إنذار/إخلاء طرف...)
- أرشيف مرفقات لكل موظف

**السبب:** المستودع الحالي **عام (Public)** — أي بيانات إضافية زي الراتب أو الآيبان أو صور الهوية ستكون مرئية لأي شخص على الإنترنت. قبل بناء هذي الميزات، يُفضّل الانتقال لحل أكثر أمانًا (مستودع خاص باشتراك مدفوع، أو نظام حقيقي بخادم خلفي).

## البيانات

يعرض الداشبورد:
- الموظفين في إجازة حاليًا
- العقود التي تنتهي خلال عدد أيام تحدده أنت (افتراضيًا 90 يومًا)
- الهويات / الإقامات التي تنتهي قريبًا

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة نفسها (لا تحتاج تعديل) |
| `employees.xlsx` | ملف البيانات — هذا هو الملف الذي تعدّله باستمرار |

## خطوات النشر على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub، مثلاً باسم `hr-dashboard`.
2. ارفع الملفين `index.html` و `employees.xlsx` في **جذر المستودع** (نفس المجلد الرئيسي، وليس داخل مجلد فرعي).
3. اذهب إلى **Settings → Pages**.
4. تحت **Build and deployment** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد **/ (root)**
5. احفظ، وانتظر دقيقة أو دقيقتين. سيظهر لك رابط الصفحة بالشكل:
   `https://<اسم-المستخدم>.github.io/hr-dashboard/`

## كيف تحدّث البيانات لاحقًا

ملف `employees.xlsx` مقسّم إلى **3 شيتات مستقلة تمامًا** — عدّل أي شيت لوحده دون التأثير على البقية، وهذا يخليك أسرع وأدق بالتحديث:

### 1) شيت "العقود"
| العمود | ملاحظة |
|---|---|
| الاسم | |
| الرقم الوظيفي | |
| القسم | |
| تاريخ بداية العقد | تاريخ حقيقي (Date)، ليس نص |
| تاريخ انتهاء العقد | تاريخ حقيقي |

### 2) شيت "الإجازات"
أضف صفًا **فقط** للموظف الذي عنده إجازة (حالية أو قادمة). لا حاجة لحذف الصف بعد انتهاء الإجازة إلا إذا حبيت تنظّف الملف — الصفحة تتجاهل أي إجازة منتهية تلقائيًا من عداد "في إجازة الآن".

| العمود | ملاحظة |
|---|---|
| الاسم | |
| الرقم الوظيفي | |
| القسم | |
| تاريخ بداية الإجازة | تاريخ حقيقي |
| تاريخ نهاية الإجازة | تاريخ حقيقي |

الصفحة تحسب تلقائيًا هل الإجازة سارية اليوم بمقارنة التاريخين — لا يوجد عمود "الحالة" تكتبه يدويًا.

### 3) شيت "الهويات"
| العمود | ملاحظة |
|---|---|
| الاسم | |
| الرقم الوظيفي | |
| رقم الهوية / الإقامة | |
| تاريخ انتهاء الهوية / الإقامة | تاريخ حقيقي |

### بعد أي تعديل
1. احفظ الملف.
2. ارفعه (Commit) على نفس المستودع بنفس الاسم `employees.xlsx` (استبدال الملف القديم).
3. افتح رابط الصفحة أو اضغط زر **"↻ تحديث"** أعلى الصفحة — البيانات الجديدة تظهر مباشرة، بدون أي تعديل على الكود.

> ملاحظة: شيت "تعليمات" داخل الملف يشرح نفس النقاط بالعربي لأي شخص آخر يتولى تعبئة الملف مستقبلًا.
> **مهم:** أسماء الشيتات لازم تبقى بالضبط كما هي (العقود / الإجازات / الهويات) — لو غيّرت اسم أي شيت، الصفحة ما راح تلقاه وتطلع رسالة تنبيه بأعلى الداشبورد.

## تجربة الملف قبل رفعه (اختياري)

يمكنك فتح `index.html` مباشرة على جهازك والضغط على زر **"📂 تحميل ملف آخر"** لمعاينة أي نسخة من الإكسل قبل رفعها على GitHub — هذا للمعاينة فقط ولا يغيّر الملف الأساسي في المستودع.

## تخصيص حد التنبيه

فوق الصفحة يوجد حقل **"حد التنبيه (أيام)"** — غيّره من 90 إلى أي رقم تريد (مثلاً 60 أو 30) وستتحدث كل الجداول والبطاقات تلقائيًا حسب الرقم الجديد، دون الحاجة لتعديل أي ملف.
